# Mangle

Landing turística responsive y móvil primero para Mompiche, Isla Portete y Muisne. HTML, CSS y JavaScript nativos: sin dependencias, compilación ni servidor necesarios.

## Desarrollo
Servir esta carpeta con cualquier servidor estático. Publicar en Vercel como proyecto **Other**, sin comando de build y con directorio de salida `.`.

## Identidad
Verde profundo #1E4D3C, mar profundo #0F6B73, arena #DCCCB0, marfil #FAF9F4, carbón #2E2E2E. Wordmark tipográfico cursivo con Pacifico; no constituye un archivo de logo original.

## Contenido y funcionalidades
Menú móvil, fichas accesibles en diálogo, enlaces a búsquedas de zonas en Google Maps y selector de recomendaciones editoriales. Las secciones de hoy no ofrecen eventos en vivo. No hay precios, negocios aliados, números telefónicos ni reseñas inventadas. WhatsApp e inscripción de negocios permanecen indicados como próximos hasta recibir contactos oficiales. No se recogen datos personales.

Referencia territorial: https://ecuador.travel/opciones-turisticas-en-muisne/
Fotografías ilustrativas de ambiente servidas desde Unsplash; no identifican destinos ni negocios específicos. Tipografías desde Google Fonts. Estos recursos requieren conexión a Internet.
